# 使用说明

本文件覆盖：安装、功能介绍、操作指引、常见问题（FAQ）、未测试项，以及问题反馈方式。

适用版本：v1.0.0。如果你使用的是更新的版本，请以「关于与说明」页内显示的版本号为准。

---

## 一、安装步骤

本工具无需安装，绿色运行。

1. 从 [Releases](https://github.com/fylm-233/SplashFontReplacer-多合一启动图字体UI替换器/releases/latest) 页面下载以下任一文件：
   - `多合一启动图字体UI替换器.exe`（单文件版，推荐）
   - `多合一启动图字体UI替换器-目录版.zip`（目录版，解压后运行 `多合一启动图字体UI替换器.exe`）
2. 放到任意目录即可，建议放在非系统盘的非一次性目录（避免被清理工具误删）。
3. 首次运行单文件版时，程序会先解压约 1 秒到本地缓存，之后再启动是秒开。
   - 解压目录：`%LOCALAPPDATA%\MultiReplacer\app\<构建标识>\`
   - 解压日志：`%LOCALAPPDATA%\MultiReplacer\logs\bootstrapper.log`
4. 运行只需要 .NET 是**自包含**的，不需要另外装 .NET 运行时或 Windows App Runtime。

> **目录版 vs 单文件版**：两者功能完全一致。若你的杀毒软件对自解压行为敏感，请使用目录版。
> 若被 SmartScreen 拦截（未签名的个人发布程序），点「更多信息 → 仍要运行」即可。

### 运行环境要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 1809（内部版本 17763）或更高，Windows 11 亦可；x64 |
| 运行时 | 无额外要求（.NET 8 自包含打包） |
| 磁盘 | 单文件版首次解压需约 400 MB 可用空间（解压到 `%LOCALAPPDATA%`） |
| 权限 | 修改 `C:\Program Files\` 下的文件时需要管理员权限，工具会自动请求提权 |

## 二、功能介绍

程序左侧导航分为五个页面，每个模块独立备份、独立还原，互不影响。

### 1. 达芬奇启动图

替换 DaVinci Resolve（`Resolve.exe`）内嵌的 PNG 资源，包含启动画面与 Logo 的不同 DPI 变体。做法是等长重建 PNG 覆盖原资源块，**替换后文件大小与 PE 结构不变**。

### 2. 启动图（Adobe 等）

支持以下软件的启动画面，四条写回通道由程序自动选择：

| 家族 | 识别方式 | 写回通道 |
| --- | --- | --- |
| Adobe 全系（AE / PS / PR / AI / ID / IC / CH / AN / AU / AME / LR / ME / DW / BR 等） | 默认扫描 `C:\Program Files\Adobe`，并叠加注册表 `InstallPath` | PE 资源 / 松散图片 / 容器内嵌 / jar 条目 |
| Unreal Engine | `Engine\Binaries\Win64\UnrealEditor.exe` | 松散图片 `Engine\Content\Splash` |
| Autodesk Maya | `bin\maya.exe` | 松散图片 `splash\icons\bin` |
| Autodesk 3ds Max | `3dsmax.exe` | 松散图片 `UI_ln\icons\plugcfg` |
| JetBrains 全家桶（IDEA / PyCharm / WebStorm / CLion / GoLand / Rider / DataGrip / PhpStorm / RubyMine） | `bin\*.exe` + `lib\*.jar` | jar 条目 `lib/plugins` |
| Visual Studio 2022 | `Common7\IDE\devenv.exe` | PE 资源 / 松散图片 |
| Live2D Cubism | `CubismEditor.exe` | jar 条目 `lib/resources` |

> CLIP STUDIO PAINT 已放弃适配（主程序与全部 DLL 内无尺寸符合的 PNG/BMP 大图，启动图应为私有压缩格式或代码直接绘制），因此不再出现在软件列表里。

### 3. 达芬奇 UI 字体

替换 `platforms\qwindows.dll`（Qt 平台插件）字体回退表中的字体族名。列表只显示**能放进当前槽位**的 ASCII 字体族名，因此不会出现装不进去的字体。

### 4. Adobe 字体（AE / PR / ME / AU 等）

重建 Adobe AIR 语言包 `Dictionaries\<locale>\<app>_<locale>.dat` 中的 `FontStyle` 字体键（字号 + 字体），并按签名文件记录的算法同步摘要，从而在界面上改变字体与字号。支持 CS6–2026 各版本格式自适应。

> 只覆盖使用 AIR 语言包 `FontStyle` 键的产品（AE/PR/ME/AU 等）。
> Photoshop / Illustrator / InDesign 的界面字体不在这类文件里，不在支持范围内。

### 5. 关于与说明

显示版本号、当前权限状态（标准权限 / 管理员模式）、模块边界和数据目录入口，可直接打开配置、日志、备份三个目录。

## 三、操作指引

通用步骤：**先退出目标软件 → 在工具里扫描 → 选中目标 → 选择替换图 → 应用 → 重启目标软件查看效果**。

### 3.1 启动图（Adobe 等）

1. 打开「启动图（Adobe 等）」页面，已安装软件会自动列出（默认根 `C:\Program Files\Adobe`，找不到时回落到注册表与常见安装位置）。
   - 若一个都没扫到，点「浏览目录…」手动指定软件根目录，工具会按主程序名反推产品与家族；
   - 或点「浏览 exe…」直接指向可执行文件。
2. 选中软件后自动填入目录并扫描。扫描结果按「疑似启动图」打分排序，首选通常就是标准尺寸那张；同一张图的多分辨率变体（DPI 组）会自动成组。
3. 选中一条，右侧显示原图。用「仅启动图 / 仅 Logo / 最小边长 / 关键字」可缩小范围；按 Shift / Ctrl 可多选。
4. 点「选择新的 png…」，支持 PNG / JPG / BMP：
   - 源图与目标尺寸不同时，默认**等比裁切**铺满（不拉伸变形）；
   - 需要填满同一张图时，可切换为「拉伸」。
5. 点「应用替换」。需要写 `C:\Program Files\` 下文件时会自动请求管理员权限。
6. 写入成功后自动重新扫描刷新。「还原备份」可随时回滚，「打开备份目录」可查看所有 `.bak` 与清单文件。

### 3.2 Adobe 字体

1. 工具自动检测已安装的 Adobe 应用，也可手动选择 `Dictionaries` 目录。
2. 在候选列表中选择字体（提供搜索），设置大号 / 中号 / 小三档字号。
3. 「应用」时先以**首次备份**为基线重建语言包（避免反复叠加），再按签名文件记录的算法同步摘要。
4. 写入 `Program Files` 会自动请求管理员权限。
5. 「恢复官方语言包」回到备份基线；重启目标软件生效。

> 备份基线是「首次应用时的原样快照」。若在第一次应用前文件已被其他工具改过，恢复结果就是那一份快照。
> 若替换后界面字体未变化，请检查是否选到了仅影响某些面板的键，或该产品是否确实使用 AIR 语言包字体键。

### 3.3 达芬奇启动图

1. 选择 `Resolve.exe`（也可用「自动查找」）。
2. 点「扫描」，等待列出内嵌 PNG 资源。
3. 用筛选项缩小范围，可多选多分辨率变体。
4. 点「选择替换图」，工具会按目标资源长度**等长重建** PNG。
5. 「应用」写回，必要时自动请求管理员权限；可随时还原。

### 3.4 达芬奇 UI 字体

1. 工具自动定位 `platforms\qwindows.dll`（也可手动指定）。
2. 列表只显示能放进当前槽位的字体族名，推荐 `Microsoft YaHei UI`。
3. 选中后点「应用字体」；首次应用会写入 `<dll>.font.original.bak`。
4. 重启 DaVinci Resolve 生效；「恢复字体备份」可还原。

### 3.5 管理员模式

- 以管理员身份运行时，界面右上角会显示「选择器：Win32 公共对话框（管理员模式）」。
  原因：WinRT 文件选择器在提权进程中会被系统拒绝（`E_ACCESSDENIED`），因此所有「选择文件 / 选择目录」自动切换到 Win32 公共对话框，功能完全一致，只是回填路径需要点一次「确定」。
- 管理员模式下 Windows 的 UIPI 会拦截拖放，请改用「浏览…」按钮选文件。
- 底部状态栏在版本号左侧显示当前权限状态（标准权限 / 管理员模式）。

## 四、数据与备份位置

| 内容 | 路径 |
| --- | --- |
| 配置 | `%APPDATA%\MultiReplacer\settings.json` |
| 日志 | `%LOCALAPPDATA%\MultiReplacer\logs\yyyy-MM-dd.log` |
| 启动器日志 | `%LOCALAPPDATA%\MultiReplacer\logs\bootstrapper.log` |
| 备份 | `%LOCALAPPDATA%\MultiReplacer\backup\` |
| 运行缓存 | `%LOCALAPPDATA%\MultiReplacer\app\<构建标识>\` |

单文件版程序目录不稳定（换版本可能换目录），因此配置、备份、日志一律放在用户目录，升级或移动 exe 不会丢数据。「关于与说明」页可直接打开这三个目录。

## 五、常见问题（FAQ）

**Q1：点击「应用替换」后目标软件打不开 / 报错？**
A：先在工具里点「还原备份」恢复原文件。绝大多数情况是替换图本身有问题（如格式不是工具要求的、或写入时目标软件仍在运行）。请务必在**完全退出目标软件**后再操作。

**Q2：替换后启动图没变化？**
A：① 确认已完全退出并重启目标软件；② 确认替换的是「疑似启动图」评分最高的那一项而不是 Logo；③ 部分软件会把启动图缓存到 `%LOCALAPPDATA%`，需清理后重试；④ 确认多分辨率变体是否都替换了（同一张图的高 DPI 变体）。

**Q3：提示「无法把新 PNG 压缩到目标长度」？**
A：这表示容器（例如 Photoshop 的 `PSIconsHighRes.dat`）里图片区域长度固定，而新图太大。信息里会给出「最省的一版仍有 X 字节，超出百分之几」。解决方向：换一张细节更少、更干净的图；或换一张本身就是同尺寸导出的图；或适当降低目标图尺寸后重新导出。

**Q4：写入后文件数字签名失效，软件还能用吗？**
A：可以正常加载。Adobe 系程序不会因签名失效拒绝加载资源。若你所在环境有安全策略会校验签名，请先评估影响再操作。

**Q5：为什么 Adobe 字体只支持 AE / PR / ME / AU 这类？**
A：这些产品使用 AIR 语言包的 `FontStyle` 键控制界面字体；Photoshop / Illustrator / InDesign 的界面字体不在同一类文件里，因此不在支持范围内。

**Q6：管理员模式下选完文件没有自动回填路径？**
A：管理员模式使用 Win32 公共对话框，点「打开 / 确定」后路径才会回填。若对话框弹出后没有反应，请确认点击的是对话框内的按钮，而不是主窗口。

**Q7：换电脑 / 更新版本后备份还在吗？**
A：在。备份、日志、配置都在 `%LOCALAPPDATA%\MultiReplacer\`，不随程序移动而丢失。

**Q8：会修改系统或其他软件吗？**
A：只写入选定的目标文件，且首次写回前自动生成 `.bak` 备份。不会安装驱动、不会常驻后台、不联网。

**Q9：单文件版启动报 0x80040111 / 打不开？**
A：通常是解压失败（磁盘空间不足或杀毒软件拦截）。查看 `%LOCALAPPDATA%\MultiReplacer\logs\bootstrapper.log`；或改用目录版。

**Q10：替换图支持哪些格式？**
A：PNG / JPG / BMP。目标资源是 BMP 时会自动按 BMP 编码写回。

## 七、问题反馈

如果遇到问题或有功能建议，请在仓库的 [Issues](https://github.com/fylm-233/SplashFontReplacer-多合一启动图字体UI替换器/issues) 页面提交（仓库已提供 Bug 报告与功能建议模板）。

提交 Bug 时请尽量包含以下四类信息，可以大幅缩短定位时间：

1. **复现步骤**——按顺序写清点了什么、选了什么文件、什么软件什么版本；
2. **操作系统版本**——如 Windows 11 23H2 (build 22631.3447)；
3. **运行环境信息**——本工具版本（「关于与说明」页可见）、目标软件与版本、是否以管理员身份运行、单文件版还是目录版；
4. **错误日志**——`%LOCALAPPDATA%\MultiReplacer\logs\` 下对应日期的 `.log` 文件内容（可贴关键片段，注意脱敏个人信息）。

> 涉及具体文件损坏时，请附上工具是否提示「已生成备份」，以及备份目录内清单文件内容。
