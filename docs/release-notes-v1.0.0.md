## 适用操作系统

| 项目 | 要求 |
| --- | --- |
| 操作系统 | **Windows 10 版本 1809（内部版本 17763）及以上**，x64；Windows 11 亦可 |
| 架构 | x64（不支持 ARM64 原生运行，可通过 x64 仿真运行，未验证） |
| 多显示器 / 缩放 | 100%–200% 缩放已验证，200% 以上未验证 |
| 本地化 | 界面为简体中文；不依赖系统区域设置 |

## 最低运行环境要求

| 项目 | 要求 |
| --- | --- |
| .NET 运行时 | **无需安装**（.NET 8 自包含打包） |
| Windows App Runtime | **无需安装**（Windows App SDK 自包含） |
| Visual C++ 运行库 | 无需安装（随包提供） |
| 磁盘空间 | 单文件版首次解压约需 400 MB 可用空间（解压到 `%LOCALAPPDATA%\MultiReplacer\app\<构建标识>\`） |
| 内存 | ≥ 4 GB 可用（替换 1532×1032 启动图时峰值约 300 MB） |
| 权限 | 修改 `C:\Program Files\` 下文件时需管理员权限，工具会自动请求提权；界面本身不需要提权 |
| 依赖的第三方组件 | 仅 Windows 系统组件（Win32 资源 API、WIC 图像编解码器） |

## 已知限制

- **已放弃适配**：CLIP STUDIO PAINT（主程序与全部 DLL 内无尺寸符合的 PNG/BMP 大图，启动图应为私有压缩格式或代码直接绘制）。
- **未测试项**：达芬奇启动图 / 达芬奇 UI 字体模块、Adobe 启动图（除 PS 2026 / AE 2026 之外）、Adobe 字体（除 AE 2026 之外）均未在目标软件的真实安装上端到端实测。完整清单见 [`docs/使用说明.md`](使用说明.md)「六、未测试项」。
- Windows 前台锁导致「管理员模式下选完文件点确定回填路径」未做自动化验证，需人工点一次。
- 修改商业软件资源文件属于非官方修改，请在合法授权的软件上使用，并自行承担风险。

**完整改动说明**：本版本将原本分散的三个工具整合为单一程序，并重写了启动图导入链路——此前存在「连自己导出的原图也放不回去」的问题，根因是压缩档位不足（只试到 zlib level 6）、WIC 1:1 也重采样且用预乘 alpha，以及有损降级阶梯被「整张图没有全透明像素」这一条件整体挡掉。三者均已修复并有上述实测数据佐证。
